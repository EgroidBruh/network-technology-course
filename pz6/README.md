# Список задач на FastAPI и Jinja2

## Запуск

Нужен Python 3.10 или новее. Выполняйте команды из папки проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn api:app --host 127.0.0.1 --port 8000 --reload
```

В Windows вместо `source .venv/bin/activate` выполните `.venv\Scripts\activate`
в командной строке cmd.

Откройте <http://127.0.0.1:8000/todo> (главная страница `/` также ведёт на список).
Введите текст задачи и нажмите «Добавить задачу». ID присваивается автоматически.
Нажмите на текст задачи в списке, чтобы открыть её отдельную страницу.
Форма на странице отдельной задачи тоже добавляет новую задачу и показывает список.

Для остановки сервера нажмите `Ctrl+C`.

## Дополнительные методы API

Документация: <http://127.0.0.1:8000/docs>.

- `GET /todo` — HTML со списком задач.
- `POST /todo` — добавление через поле формы `item`, ответ в HTML.
- `GET /todo/{todo_id}` — HTML с одной задачей; для неизвестного ID возвращается 404.
- `PUT /todo/{todo_id}` — изменение текста, JSON: `{"item": "Новый текст"}`.
- `DELETE /todo/{todo_id}` — удаление одной задачи.
- `DELETE /todo` — удаление всех задач.

Изменение и удаление доступны через `/docs`. После них обновите страницу списка.
Задачи хранятся в памяти: при остановке или перезагрузке сервера они исчезают.
Bootstrap загружается через CDN, поэтому для оформления нужен интернет.
Без него форма, ссылки и список продолжают работать.
